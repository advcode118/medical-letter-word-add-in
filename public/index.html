Medical Letter

A Microsoft Word sidebar for structured medical letters. The document stays a normal Word file. This is a document tool, not a diagnostic system. Bundled lists are demonstration data only.

Skip Word’s Catalog Url box. It only accepts a SharePoint https:// catalogue, not this website.

Download the installer (Install-MedicalLetter.cmd)

Install in Word (once)

  1. Close Word.
  2. Download Install-MedicalLetter.cmd and double-click it. If Windows warns you, choose More info → Run anyway.
  3. Open Word. On the Home tab, choose Medical Letter.

If the installer is blocked, open PowerShell and paste:

irm https://advcode118.github.io/medical-letter-word-add-in/Install-MedicalLetter.ps1 | iex

Then close Word completely and open it again. You need internet when the sidebar loads. Letter content stays in Word on your computer.

Write a letter

  1. Open a blank document, or a letterhead with empty body text.
  2. Fill in patient details, then pick items from the lists. Use Other for a one-off value that is not in the list.
  3. Click Populate Letter. On a blank document this inserts the letter layout and fills in the placeholders.
  4. Or click Insert template first, then populate when you are ready.

Empty fields are left as placeholders such as {{DIAGNOSIS}} until you fill them and populate again.

Customise

Open the Customise tab to edit the letter template, lists, and reusable paragraphs. Those changes stay on this computer. Use Export library / Import library to share lists with a colleague (this does not include patient data).
